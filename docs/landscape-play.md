# スマートフォンの横向きプレイ

画面を横向きにすると、中央のライブ映像モニターを囲むように左右3レーンずつへ切り替わります。ステージから飛んでくるレスを、下部の6色のペンライトで受け止める構成です。画面の向きは強制せず、縦向きに戻せば従来の表示に戻ります。

- 対象：横長で幅568 CSS px以上、高さ600 CSS px以下の画面。横向きスマホと、小さくしたPCブラウザで確認できます。
- 中央に200×200px以上のYouTube公式プレーヤーを残し、6レーンとボタンはその左右へ配置します。動画の操作部分にノーツ・ボタンを重ねません。
- 6レーンの幅とボタンのサイズはすべて同じです。モニター用の中央余白を取り、各ボタンは幅44px以上・高さ60px以上、下端に44px以上の余白を保ちます。
- ノーツの縦方向の進み方は全レーン共通です。左右のステージから手前へ広がる横方向の遠近感だけを変えます。曲の時刻・判定幅・入力補正・表示時間の設定・MIDI割り当ては変更しません。
- DDと箱オシの文字は両側に表示し、中央モニターの裏で種類が分からなくなることを避けます。箱オシは左右それぞれの内側のボタンから外へスワイプします。
- 再生操作は中央下、曲名とスコアは左右の上部、詳細は上部中央に配置します。設定や詳細を開いてもレーンを押し下げません。
- 会場は既存のステージ・6人のシルエット・ペンライトの客席を使います。背景はサイズ変更時にだけ描き直し、プレイ中はキャッシュを利用します。

縦横を切り替えても動画や譜面を作り直しません。再生・一時停止の状態やスコアを保持します。YouTubeの広告や端末の表示設定の影響は、実機でも確認してください。ブラウザの下部ツールバーや左右の切り欠きにはsafe-areaと操作ボタンの余白で対応します。

GitHub Pagesはマージ後のテスト配信で確認できます。本番サイトは同じコミットの `rhythm-site` をFTP更新するまで変わりません。端末で縦画面に固定している場合は、端末の画面回転ロックを解除してください。全画面表示は必須ではありません。
