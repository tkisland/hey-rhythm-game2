# スマートフォンの横向きプレイ

画面を横向きにすると、中央のライブ映像モニターの脇から、弧を描いて手元へ飛んでくる6レーンに切り替わります。ステージから飛んでくるレスを、下部の連続した6色のペンライトで受け止める構成です。画面の向きは強制せず、縦向きに戻せば従来の表示に戻ります。

- 対象：横長で幅568 CSS px以上、高さ600 CSS px以下の画面。横向きスマホと、小さくしたPCブラウザで確認できます。
- 中央に200×200px以上のYouTube公式プレーヤーを残し、ノーツはその左右から飛び、ボタンは映像の下に一列で配置します。動画の操作部分にノーツ・ボタンを重ねません。
- ノーツと判定表示は中央の最大560pxへ集め、周辺視野へ広がりすぎないようにします。映像脇から外へ膨らむ弧を描き、映像の下へ回り込んで各ペンライトの中心へ着地します。判定位置と入力ボタンは同じ位置です。
- 6レーン同士の幅と、6ボタン同士のサイズはそろえます。入力列の白・赤の間の空きは24pxを基準にし、映像用の240pxの余白から分離します。中央を横切る経路に動画や操作ボタンを置かず、各ボタンは幅44px以上・高さ60px以上、下端に44px以上の余白を保ちます。
- 弧に沿うノーツの高さと表示サイズは全レーン共通です。同時刻のノーツは横一列を保ち、着地直前はそれぞれのボタンへ縦方向に入ります。長オシの帯・オシ変の経路・判定エフェクトも同じ軌道と終点にそろえます。曲の時刻・判定幅・入力補正・表示時間の設定・MIDI割り当ては変更しません。
- DDと箱オシの文字は両側に表示し、中央モニターの裏で種類が分からなくなることを避けます。箱オシは左右それぞれの内側のボタンから外へスワイプします。
- 再生・再開・やり直しは左上、曲名とスコアはプレイ範囲の左右上部、詳細と設定・選曲は右上に配置します。横向き時だけヘッダーのロゴを隠して操作のスペースを確保します。設定や詳細を開いてもレーンを押し下げません。
- 会場は既存のステージ・6人のシルエット・ペンライトの客席を使います。背景はサイズ変更時にだけ描き直し、プレイ中はキャッシュを利用します。

縦横を切り替えても動画や譜面を作り直しません。再生・一時停止の状態やスコアを保持します。YouTubeの広告や端末の表示設定の影響は、実機でも確認してください。ブラウザの下部ツールバーや左右の切り欠きにはsafe-areaと操作ボタンの余白で対応します。

GitHub Pagesはマージ後のテスト配信で確認できます。本番サイトは同じコミットの `rhythm-site` をFTP更新するまで変わりません。端末で縦画面に固定している場合は、端末の画面回転ロックを解除してください。全画面表示は必須ではありません。
